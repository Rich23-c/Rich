# 🐾 ร้านขนมแม้ว (Snack by Maew) - แยก 2 เว็บอิสระ

ระบบเว็บร้านขนมแม้วที่แยกการทำงานระหว่าง **"เว็บสำหรับลูกค้า"** และ **"เว็บสำหรับแอดมิน"** ออกจากกันอย่างอิสระ 100%

---

## 🌐 2 เว็บไซต์แยกกัน (Separated Websites)

| เว็บไซต์ | ที่อยู่ (URL) | พอร์ต (Port) | ปุ่มเปิดลัด (Batch) | รายละเอียด |
| :--- | :--- | :--- | :--- | :--- |
| **🍪 เว็บลูกค้า** (Customer Store) | **http://localhost:3000** | `3000` | [`start-customer.bat`](start-customer.bat) | สำหรับลูกค้าสั่งซื้อขนม ติ๊กเลือกขนม ระบุจำนวน สรุปราคา และแนบสลิป (ไม่มีปุ่ม Admin ให้เห็น) |
| **🔐 เว็บแอดมิน** (Admin Portal) | **http://localhost:3001** | `3001` | [`start-admin.bat`](start-admin.bat) | สำหรับร้านแม้วจัดการราคา กำหนดรูปภาพ ตรวจสอบสลิป และดูรายการสั่งซื้อ (PIN: `1234`) |

---

## ✨ การทำงานของแต่ละเว็บ

### 1. 🍪 เว็บลูกค้า (Port 3000)
* **สอบถามข้อมูลลูกค้า**: กรอกชื่อลูกค้า (จำเป็น), เบอร์โทร และที่อยู่จัดส่ง
* **เลือกเมนูขนมแบบติ๊กถูก**: มีช่องติ๊กถูกเพื่อเลือกขนมแต่ละชนิด
* **เลือกระบุจำนวน**: กำหนดจำนวนชิ้นได้ตามต้องการ
* **สรุปราคาเรียลไทม์**: คำนวณราคาย่อยและราคารวมทั้งหมด
* **PromptPay QR Code**: สร้าง QR Code สำหรับสแกนจ่ายตามยอดรวม
* **แนบรูปสลิป & ตรวจสอบยอดด้วย AI**:
  - ✅ สลิปตรงยอด: แจ้งเตือนสีเขียว
  - ⚠️ สลิปไม่ตรงยอด: แจ้งเตือนทันทีว่าขาดหรือเกินกี่บาท

### 2. 🔐 เว็บแอดมิน (Port 3001)
* **รหัส PIN เข้าใช้งาน**: `1234` (สามารถเปลี่ยนได้ที่แท็บตั้งค่า)
* **จัดการเมนูขนม**:
  - เพิ่มขนมใหม่ / แก้ไขขนม
  - **กำหนดราคา 1 อันกี่บาท**
  - **กำหนดรูปภาพเองได้**: อัปโหลดไฟล์จากคอมพิวเตอร์ หรือใส่ลิงก์ URL รูปภาพ
  - เปิด/ปิดการขายชั่วคราว หรือลบเมนู
* **ตรวจดูออเดอร์ & รูปสลิป**:
  - ดูรูปสลิปแบบขยายใหญ่ (Zoom)
  - ดูผลวิเคราะห์จาก AI (ยอดเงินที่ตรวจพบ, ธนาคาร, วันเวลา, ผู้โอน)
  - อัปเดตสถานะออเดอร์: `รอตรวจสอบ` ➔ `ยืนยันยอดเงินแล้ว` ➔ `กำลังเตรียมขนม` ➔ `จัดส่งแล้ว`

## 🚀 วิธีเปิดใช้งาน

1. **เปิดทั้ง 2 เว็บพร้อมกัน**:
   - ดับเบิ้ลคลิก **[`start.bat`](start.bat)** (จะเปิดทั้งเว็บลูกค้า :3000 และเว็บแอดมิน :3001 พร้อมกัน)
2. **เปิดเฉพาะเว็บลูกค้า**:
   - ดับเบิ้ลคลิก **[`start-customer.bat`](start-customer.bat)**
3. **เปิดเฉพาะเว็บแอดมิน**:
   - ดับเบิ้ลคลิก **[`start-admin.bat`](start-admin.bat)**
